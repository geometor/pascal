geometor.pascal.projective¶

Exact symbolic projective geometry and conic primitives for Blaise Pascal’s constructions.

Provides 100% exact SymPy implementations of rational stereographic circle parameterization, five-point Veronese conic equations, coconicity tests, Michel Chasles’s cross-ratio on conics, line meets, and integration with geometor.divine for emergent golden section detection.
